# INDEX — 记忆入口

> 规范源：`memory/`（位置可用 `.memory-root` / `$MEMORY_ROOT` / `--root` 指定）

## 读取顺序

1. **本文件**（完成）
2. 判断任务属于哪个项目 → **只读那一个** `projects/<项目>/STATE.md`
3. 要**写**记忆时 → 读 `SCHEMA.md`
4. 仍然不足 → 才查 `import/`（全部按 `legacy-summary` 对待）

**不要默认加载全部项目文件，也不要默认加载 `import/`。**

**无法确定属于哪个项目 → 直接问用户，不要猜。**

## 权威层级（冲突时谁说了算）

**用户最新明确表达** ＞ **当前实际文件 / 可复现测试** ＞ **本记忆库的项目文件** ＞ **旧摘要与历史快照**

## 项目速查

| 项目文件 | 内容 |
|---|---|
| `projects/_TEMPLATE/STATE.md` | **新项目从这里复制** |
| `projects/<你的项目>/STATE.md` | 各项目现状（只读当前那一个） |

> 新增项目：复制 `_TEMPLATE/` 改名，填 frontmatter，然后在本表登记一行。

## 已决定不做（避免重复讨论）

把已经明确否决过的事写在这里，附**理由**与**重新评估的条件**。
例：

- **不引入向量数据库** — 当前规模 grep 足够；当记忆文件数达到数百个量级时重新评估。
- **不给资料不足的项目编造状态** — 空壳记忆比没有记忆更糟。

## 常驻预算（防膨胀）

**每次新对话必读的只有两个文件：工作区 `AGENTS.md` + 本文件。**
目标合计 **≤ 10 KB**。超出就从常驻文件往按需文件搬：

| 常驻（每次读） | 按需（用到才读） |
|---|---|
| `AGENTS.md` | `SCHEMA.md`（写记忆时） |
| `INDEX.md`（本文件） | `GLOBAL_RULES.md`（要偏好细节时） |
| — | `ARCHITECTURE.md`（要设计史与教训时） |
| — | `projects/*.md`（只读当前项目） |

**改常驻文件时先算大小**（`python tools/cost.py`）。
长表格、长清单、推导、教训一律放按需文件。

## 相关文件

| 文件 | 作用 |
|---|---|
| `SCHEMA.md` | 证据标记、字段、来源标签、冲突流程（**写之前必读**） |
| `ARCHITECTURE.md` | 本系统设计、冲突记录、踩坑教训 |
| `GLOBAL_RULES.md` | 用户长期偏好与硬约束（细节） |
| `events/` | 事件与决策日志（**有界增长**，见 `events/README.md`） |
| `tools/memory-check.py` | 自检：秘密 / 证据 / 完整性 / 常驻预算 |
| `tools/cost.py` | 开销报告：常驻 vs 按需 vs 磁盘 |
| `tools/baseline.py` | 目录哈希基线（冻结保护 or 变更侦测） |
